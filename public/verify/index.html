Compare a file with the public log.

This page computes a file's SHA-256 fingerprint in your browser and looks for the same value in the public attestation log. A match shows that identical bytes were listed in a log row. It does not independently prove when or how the file was captured, who submitted it, or that the log is append-only.

Server receipt time

Each accepted row records a server-side receipt time. That timestamp describes when the service received the submission, not necessarily when the file was captured.

Challenge field

The log can include a session challenge code. This page does not inspect media content or independently confirm that the code appears in the recording.

Content fingerprints

The checker recomputes the selected file's hash locally and searches the public log. It does not upload the file.

Pick a photo or video downloaded from this record. The hash is computed locally—the file never leaves your device.

NOT FOUND can result from any byte-level change, including recompression, screenshots, and re-saving. A listed hash is a comparison result, not a cryptographic signature or independent authenticity finding. For discrepancies: ap@michealrayberry.com.

Inspect the public feed yourself

The site publishes a sanitized, machine-readable attestation feed containing only accepted capture-attested rows and their file hashes. A listed value remains a claim recorded by the current system rather than an independent verification.
